# NYC Taxi Analytics Platform

A data engineering project that processes NYC Taxi trip data using Python, PySpark, PostgreSQL, Airflow, and Power BI.

## Tech Stack

- Python
- Pandas
- PySpark
- PostgreSQL
- Airflow
- Power BI

## Project Goals

- Build ETL pipelines
- Process large datasets
- Store analytics-ready data
- Create business dashboards
- Automate workflows
